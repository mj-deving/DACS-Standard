# DACS Proposal Bundle

Prepared for handoff to the DACS maintainer team.

Date checked: 2026-06-28

Contents:

- `01-maintainer-memo.md`
  Direct proposal for restructuring the standard around a thinner core, stage modules, hooks, profiles, and separated registries/mappings/governance docs.
- `02-rewritten-table-of-contents.md`
  Proposed target document set and high-level chapter layout.
- `03-migration-plan.md`
  Recommended sequencing for moving from the current docs to the target structure with low rewrite risk.
- `04-current-to-future-move-map.md`
  Current-document to future-document mapping, including what should stay, move, shrink, or split.
- `05-double-check-audit.md`
  Verification notes: what was checked, what is high-confidence, and where the proposal is editorial judgment rather than protocol fact.
- `06-sources.md`
  Source URLs and date-of-review notes.

Recommended reading order:

1. `01-maintainer-memo.md`
2. `02-rewritten-table-of-contents.md`
3. `03-migration-plan.md`
4. `04-current-to-future-move-map.md`
5. `05-double-check-audit.md`
